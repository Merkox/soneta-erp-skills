# Pola i właściwości klasy biznesowej: `Soneta.Core.Conversation.ThreadCategory`
Nazwa tabeli: `ThreadCategories`
Tytuł: Kategoria komunikacji
Opis: Słownik kategorii komunikacji (wątków dyskusji, aktualności). Każda kategoria posiada nazwę i kolor tła kafelka, umożliwiając wizualne grupowanie i rozróżnianie wpisów.
Tabela konfiguracyjna: Tak

| Pole | Typ | Rodzaj | Tytuł | Opis |
|------|-----|--------|-------|------|

| Name | `string` | bazodanowe |  |  |
